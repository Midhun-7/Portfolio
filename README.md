# Midhun Muraleedharan - Portfolio

A modern, single-page developer portfolio built to showcase my projects, skills, and experience as a Software Engineer.

## 🚀 Features

- **Dark Theme UI**: A custom-designed, sleek dark mode interface with deep slate/indigo colors and glowing accents.
- **Scroll Animations**: Smooth, staggered entrance animations triggered on scroll using Framer Motion.
- **Bento Grid**: A modern grid layout showcasing location, education, interests, and coding philosophy.
- **Dynamic Typewriter**: Hero section features a typewriter effect looping through various engineering roles.
- **Interactive Navigation**: Sticky, blurred header with active scroll-spy navigation.

## 🛠️ Tech Stack

- **Framework**: [React.js](https://reactjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Scroll Handling**: `react-scroll`
- **Fonts**: JetBrains Mono & Inter (Google Fonts)

## 💻 Local Development

Clone the repository and run the application locally:

```bash
# Clone the repository
git clone https://github.com/Midhun-7/portfolio.git

# Navigate to the project directory
cd portfolio

# Install dependencies
npm install

# Start the development server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## 📦 Build for Production

To build the app for production to the `build` folder:

```bash
npm run build
```
